# MuJoCo Robotic Assets

This package provides a collection of assets for simulating several commonly used robots in MuJoCo.

## Assets


| Robot | Description | Reference | License |
|-------|-------------|-----------|---------|
| [__Go2__](resources/go2/) | 12-DoF quadrupedal robot developed by Unitree Robotics | [Link](https://www.unitree.com/go2) | - |
| [__Go2-W__](resources/go2w/) | 16-DoF wheeled quadrupedal robot developed by Unitree Robotics | [Link](https://www.unitree.com/go2) | - |
| [__B2__](resources/b2/) | 12-DoF industrial quadrupedal robot developed by Unitree Robotics | [Link](https://www.unitree.com/b2) | - |
| [__B2-W__](resources/b2w/) | 16-DoF wheeled industrial quadrupedal robot developed by Unitree Robotics | [Link](https://www.unitree.com/b2) | - |
| [__G1__](resources/g1/) | Humanoid robot developed by Unitree Robotics (23-DoF and 29-DoF variants) | [Link](https://www.unitree.com/g1) | - |
| [__H1__](resources/h1/) | 19-DoF humanoid robot developed by Unitree Robotics | [Link](https://www.unitree.com/h1) | - |
| [__H1_2__](resources/h1_2/) | 27-DoF humanoid robot (H1 v2) developed by Unitree Robotics | [Link](https://www.unitree.com/h1) | - |
